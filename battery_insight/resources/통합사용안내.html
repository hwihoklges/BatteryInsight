3.1.0 · Windows x64 · 오프라인 통합판

BatteryInsight
변환부터 실험 연결과 비교까지

BatteryInsight.exe를 실행하면 CYC 변환, Parquet 등록·분류, 장표·샘플 연결, 지표 사전과 기존 비교 작업실을 한 프로그램에서 사용할 수 있습니다. 실행에 Python 설치·인터넷·API 키가 필요하지 않습니다. LLM 호출과 머신러닝 학습은 사용하지 않습니다.

처음 시작하기

  1. 배포 ZIP을 모두 풀고 BatteryInsight.exe 또는 바로실행.cmd를 실행합니다.
  2. 새 프로젝트 / 열기에서 데이터를 관리할 프로젝트 폴더를 선택합니다. 기본 위치는 Windows 사용자 LocalAppData의 BatteryInsight/Project입니다.
  3. 원본이 CYC면 CYC 폴더 변환·등록, 이미 Parquet이면 Parquet 폴더 등록을 누릅니다. CYC는 하위 폴더를 포함해 직접 읽고 프로젝트에 Parquet과 등록 DB를 만듭니다.
  4. 파일을 선택하고 선택 실험 정보에서 확인한 시험 종류·샘플·물리 셀·설계·배치·조건을 입력합니다. 여러 항목은 등록표 CSV/Excel로 편집할 수 있습니다.
  5. 지표·관계망·분석 탭의 현재 Parquet DB로 비교 작업실 열기를 누릅니다. 브라우저의 로컬 주소(127.0.0.1)에서 비교 기능과 지표를 각각 켜고 끌 수 있습니다.

하나로 연결된 기능

기능사용 위치
CYC → Parquet데이터·실험 분류 / CYC 대기 목록에 폴더를 추가하고 시작을 누릅니다. 여러 하위 폴더를 복수 선택하고 순서를 바꿀 수 있습니다. Restore CSV 없이 전체 레코드를 저장합니다.
Parquet 분류 DB같은 탭에서 폴더 추가, 검색, 실험 정보 편집, 등록표 CSV/Excel 교환, 승인된 폴더 분류 규칙을 적용합니다.
장표 → 실험·샘플장표·샘플 연결 / PPTX·PDF·Excel을 추가하고 근거와 실험 기록을 등록합니다. 확인된 날짜·세트·namespace·시험 종류로 후보를 찾고 사람이 연결을 확정합니다.
설계·전기화학 관계망비교 작업실에서 두 지도, 교차 비교, 레이더, 조건 통제 비교, 궤적, 상관과 셀 평균을 선택합니다.
원곡선·이상 근거비교 작업실의 근거 보기에서 저장된 실제 값을 조회합니다. 프로파일 지표의 초기 기준 대비 변화와 계산 불가 사유를 함께 제공합니다.
기존 AIM/외부 지표선택 데이터에 검증된 외부 지표를 명시적 매핑 JSON으로 연결할 수 있습니다. 기존 지표 사전과 중복 정리 결과도 프로그램에 포함됩니다.
기존 전체 분석기존 raw DB/작업실 JSON 설정과 원본 분석 JSON 설정을 같은 EXE에서 실행할 수 있습니다.

수치·단위·사이클

원본 CYC의 step_time_s, voltage_native, capacity_native는 모든 기록을 그대로 보존합니다. 원래 float32 값을 float64로 정확히 확장하고 Zstandard 수준 19로 저장합니다. 사이클 필터·다운샘플링·추가 반올림을 하지 않습니다. _org 사본도 별도 파일로 보존합니다.

CYC 헤더만으로 전압·용량 단위를 확정할 수 없습니다. 실험 정보에서 전압 V/mV, 용량 Ah/mAh/uAh를 확인한 뒤 물리 단위의 프로파일 지표를 계산합니다. 확인 전에도 원본 수치 곡선은 볼 수 있으며 물리 단위가 필요한 지표는 결측 사유를 표시합니다.

CTS가 있으면 사이클·스텝과 확인 가능한 전체 시간을 연결합니다. CTS 없는 기록도 보존하며 해당 구분 값은 null입니다. 원본의 cycle 번호를 수명 cycle로 자동 간주하지 않습니다. 비교 축은 기본적으로 기록 cycle이며 RPT 시점과 시험 종류는 확인한 등록 정보로 구분합니다.

실험 분류와 반복 실행

파일명의 날짜·세트·채널·시험 종류는 미확인 후보입니다. 자동 확정하지 않습니다. 확인된 등록 정보는 파일 해시에 연결되어 다음 실행에서 재사용됩니다. 파일이 바뀌면 재확인 상태로 남습니다.

분류 규칙은 사용자가 확인한 경로 패턴과 설계·배치·시험 조건을 적용합니다. 예를 들어 {"rule_id":"cycle_folder","path_glob":"Cycle/*","metadata":{"test_type":"Cycle"}}처럼 작성합니다. 개별 물리 셀·샘플·날짜를 폴더 규칙으로 복제할 수 없고, 기존 확인값과 규칙이 충돌하면 검토 목록으로 남깁니다.

변경 반영은 등록한 Parquet 폴더와 분류 규칙을 다시 확인합니다. 필요하면 30초 자동 반영을 켤 수 있습니다. CYC는 대기 목록에서 시작 버튼을 눌렀을 때만 변환합니다. 이전에 완료한 원본·Parquet은 삭제하지 않습니다. 원본이 변환 중 바뀌면 해당 변환을 실패로 남깁니다.

장표를 하나씩 추가할 때

  1. PPTX·PDF·Excel을 추가하고 추출된 텍스트와 위치를 확인합니다. 문서 내용은 데이터로만 취급합니다.
  2. 근거를 선택하고 실험 기록을 작성합니다. sample_id, sample_name, experiment_name과 날짜 종류·세트·namespace 등을 기입합니다. 확인 전은 draft, 근거 확인 후 confirmed로 저장합니다.
  3. 데이터 탭에서 해당 Parquet을 선택한 뒤 장표 탭의 연결 버튼에서 기록을 확정합니다. 후보가 여러 개면 하나를 직접 확인합니다.
  4. 기록 수정은 record_id를 유지한 JSON으로 기존 knowledge-records 명령을 사용할 수 있습니다. 문서 기록의 버전이 바뀌면 기존 raw 연결은 재확인 대상입니다.

이미지 표·스캔 PDF·그래프 숫자를 자동으로 해석하거나 사실로 확정하지 않습니다. 수동 확인 항목을 검토 화면에 남깁니다.

지표와 평균의 범위

시간·용량·전압만 저장한 데이터에서는 관측 평균 전압·전압 범위·용량 범위·전체 시간 범위를 계산합니다. 관측 용량 범위는 충전/방전 용량과 다른 정의입니다. 전류·CC/CV 모드가 필요한 DCIR·미분 지표 등을 임의로 재구성하지 않습니다.

프로파일 이상 검토는 동일 시험의 첫 3개 유효 cycle을 기준으로 MAD 기반 robust Z가 4를 넘는 변화를 표시합니다. 일정한 초기값에는 통계 임계값을 만들지 않고 공학 임계값 필요 상태로 남깁니다. 변화는 검토 후보이며 고장 원인이나 수명 예측으로 단정하지 않습니다.

같은 설계·배치·확인된 시험 조건·RPT 시점/관측 구간에서 여러 물리 셀의 지표를 평균합니다. 같은 셀의 반복 시험은 먼저 중앙값 하나로 정리하고, 셀마다 동일 비중으로 평균·표본 표준편차·유효 셀 수를 표시합니다. 미확인 물리 셀이나 조건은 평균에서 제외하고 개별 데이터는 유지합니다.

공식 AIM 정의는 별도 확인이 필요합니다. 프로그램에 포함된 지표 사전은 기존 코드에서 확인한 정의·출처와 중복 정리 결과이며 모든 AIM 계산식이 검증되었다는 뜻은 아닙니다. 외부 지표는 단위·정의 버전·소스 버전·관측 종료 cycle과 셀/시험 대응을 명시해야 합니다.

저장 구조와 이동

프로젝트/
  library.sqlite3              Parquet 목록·확인 정보·분류 규칙·변경 이력
  library.parquet              등록 DB의 조회용 Parquet
  converted/                   CYC에서 변환한 전체 원곡선
  profile_metrics/             단위 확인 후 계산한 프로파일 지표와 검증 해시
  external_metrics/            검증된 기존 지표
  knowledge/                   장표 근거·실험·샘플 DB와 검토 화면
  workbench/                   비교 선택·관계망·셀 평균·근거 화면
  legacy_workbenches/          기존 분석 설정의 작업실
  analysis_lake/               기존 원본 분석 결과

프로젝트 내부의 변환 Parquet은 상대 경로로 등록하므로 프로젝트 폴더를 함께 옮겨 조회할 수 있습니다. 외부 Parquet 폴더는 참조 경로로 연결합니다. 외부 원본·외부 설정 파일까지 자동 복사하지는 않습니다.

명령줄

BatteryInsight.exe cyc-import --project "D:\BIProject" --input "D:\Raw"
BatteryInsight.exe library-scan --project "D:\BIProject" --input "D:\Parquet"
BatteryInsight.exe library-open --project "D:\BIProject"
BatteryInsight.exe self-test --result-json "D:\실행기록\통합검사.json"
BatteryInsight.exe check-gui --result-json "D:\실행기록\화면검사.json"

기존 run, workbench, database-import, catalog, knowledge-* 명령도 같은 EXE에서 사용할 수 있습니다. 결과 JSON 경로는 입력과 프로젝트 바깥의 새 파일로 지정합니다.

검증된 native 입력은 제공 자료의 PNE CYC 4100/4101 형식입니다. 미지원 파일은 오류로 남깁니다. Windows 10/11 x64를 대상으로 만들었으며 Windows 11 x64에서 검증했습니다. 실행 시 임시 폴더에 내장 환경을 푸는 대기 시간이 있습니다.
