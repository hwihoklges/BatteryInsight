BatteryInsight 3.2.0 — 오프라인 통합판

ZIP 전체 압축 해제 → BatteryInsight.exe 또는 바로실행.cmd 실행

1. '새 프로젝트 / 열기'에서 프로젝트 폴더 선택
2. 'CYC 폴더 변환·등록' 또는 'Parquet 폴더 등록'
3. 파일을 선택해 '선택 실험 정보'에서 확인한 설계·배치·조건·단위 입력
4. '장표·샘플 연결'에서 PPTX/PDF/Excel 근거와 실험 기록 연결
5. '지표·관계망·분석'에서 비교 작업실 열기

기능과 지표는 비교 작업실에서 각각 켜고 끌 수 있습니다.
반복 실행에 ChatGPT/Codex 요청, Python 설치, 인터넷, API 키가 필요 없습니다.
실행 시 AI 토큰 사용량은 0입니다. 시작할 때 내장 환경을 푸는 시간이 걸립니다.

CYC 원본 숫자는 그대로 보존합니다. 전압/용량 단위를 확인한 뒤 물리 단위 지표를 계산합니다.
파일명 날짜·세트는 후보이며 자동 확정하지 않습니다. 단위나 실험명을 추측하지 않습니다.
CTS가 없어도 전체 기록을 저장합니다. _org 등 사본도 각각 보존합니다.

공식 AIM 정의가 미확정인 항목은 미설정 상태입니다. 검증된 기존 export를 명시 매핑해 연결할 수 있습니다.
시간·용량·전압만 남긴 데이터에서 전류·CC/CV 기반 지표를 재구성하지 않습니다.
기존 전체 raw 분석/DB/장표 CLI도 같은 EXE에 포함됩니다.

사용 안내: 통합사용안내.html
실행 검증: VALIDATION.json / 외부 구성요소: THIRD_PARTY_NOTICES.txt
Windows 10/11 x64 대상, Windows 11 x64 검증. 입력은 검증된 PNE CYC 4100/4101입니다.
